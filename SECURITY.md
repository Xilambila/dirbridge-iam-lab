# Security and safe use

This is a local educational preview, not a production identity service. Do not enter employee data or connect it to a real directory. Do not publish credentials, tokens, tenant details, internal addresses or customer information in code, issues, logs or screenshots.

For a vulnerability report, use GitHub's private vulnerability reporting option if the repository offers it. Otherwise contact the maintainer through the professional contact linked in the profile and request a private channel before sending technical details. Do not post a working secret in a public issue.

If a credential has been committed, revoke or rotate it at its issuing service. Removing a file does not remove the credential from history, forks or caches. History cleanup must be coordinated separately.
