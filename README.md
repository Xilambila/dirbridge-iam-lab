# DirBridge – Automatizador de Criação de Usuários no Active Directory (Azure AD)

**DirBridge** é uma API profissional de provisionamento de usuários, desenvolvida em Python com Flask, que automatiza a criação de contas no Active Directory com base em dados recebidos via formulário ou integração futura com sistemas como GLPI e Senior RH.

Este projeto está em desenvolvimento contínuo e será expandido para suportar a integração completa com processos de RH, workflows de chamados e licenciamento automático no Azure.

## 🔧 Tecnologias Utilizadas

- Python 3.11 + Flask
- Docker
- Powershell (futuramente)
- Ubuntu WSL (ambiente de testes)
- Git + GitHub
